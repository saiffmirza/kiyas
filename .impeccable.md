# Impeccable Design Context — Kiyas

## Design Context

### Users
Non-technical designers and PMs (plus the occasional engineer) running design-fidelity checks: pick a repo, paste a Figma link or drop a screenshot, get an AI comparison report. They are visual professionals — they notice sloppy UI instantly. Used on macOS desktop (Electron), sessions are short and task-focused. Secondary audience: hiring managers seeing Kiyas as a portfolio piece — the app itself must demonstrate design taste.

### Brand Personality
Crafted, warm, artisanal. The name is Arabic (قياس/كياس — "measurement/finesse") and the wordmark is calligraphic with a gold diamond accent. The product should feel like a hand-made precision instrument — bookish, editorial, humanist — not a corporate SaaS tool. Confidence through craft, not through loudness.

### Aesthetic Direction
- All-cream light theme: the whole app lives on the report's cream (#f6f0e6 family); the former navy sidebar becomes a tinted cream panel. Navy (#1b1b3a) is for ink — text, wordmarks, primary buttons. Gold (#b8963e/#d4b667) is the sole accent, used sparingly like gilding.
- Reference: Figma's approachable panel feel, but the visual north star is Kiyas's own HTML report (cream/navy/gold, translucent cards, soft shadows).
- Anti-references: dark-mode developer tools with glowing accents, generic AI dashboard aesthetics, corporate blue SaaS.
- Typography should echo the calligraphic brand — a serif or humanist display face for headings/brand moments, refined sans for UI. Monospace only where content is genuinely technical (ports, paths, selectors).

### Design Principles
1. Ink on paper: navy ink, cream paper, gold gilding — never invert to dark chrome, never add new hues except semantic red/amber/green.
2. Calm craft: generous margins, soft edges, few borders; hierarchy from type and space, not boxes-in-boxes.
3. One primary action per screen: Compare is the only loud element; everything else whispers.
4. Explain, don't gate: non-technical users always get a plain-English next step (empty states, errors, setup CTAs).
5. Earn the "how was this made?" reaction — details (wordmark, Arabic accent, report framing) should feel bespoke, not templated.
